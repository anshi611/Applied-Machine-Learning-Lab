# 🚀 Applied Machine Learning Lab
### B.Tech CSE | Semester V

Welcome to the **Applied Machine Learning Lab** repository.

This repository contains all laboratory experiments, datasets, notebooks, assignments, and reference material for the **Applied Machine Learning Lab** course.

The experiments focus on solving **real-world business problems** from domains such as Retail, Healthcare, Finance, HR, and E-commerce using Python and Machine Learning.

---

# 📚 Course Information

**Course:** Applied Machine Learning Lab

**Course Code:** CSE2512P

**Semester:** V

**Credits:** 1

**Programming Language:** Python

**Development Platform:** Google Colab / Jupyter Notebook / VS Code

---

# 🎯 Course Outcomes

After completing this laboratory, students will be able to

- Perform exploratory data analysis using Python.
- Apply machine learning algorithms to real-world datasets.
- Engineer features and preprocess data.
- Evaluate machine learning models using appropriate metrics.
- Build complete end-to-end machine learning pipelines.
- Deploy trained models using Flask/FastAPI.

# ▶ Running the Experiments

## Option 1: Google Colab (Recommended)

1. Open the notebook from the `notebooks` folder.
2. Click **Open in Colab**.
3. Upload the required dataset.
4. Run all cells sequentially.

---

## Option 2: Local Computer

Clone this repository

```bash
git clone https://github.com/yourusername/Applied-Machine-Learning-Lab.git
```

Move into the repository

```bash
cd Applied-Machine-Learning-Lab
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook

```bash
jupyter notebook
```
